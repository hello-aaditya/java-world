# No-Args Constructor
> A **No-Args Constructor** is a zero-argument constructor which is explicitly written by developer. 
> The only difference between Default Constructor & No-Args constructor is Default Constructor is generated by compiler implicitly and No-Args constructor is explicitly written by developer.

## Syntax
```java
class ClassName {
	ClassName() {
		// BODY
	}
}
```
#### Example
```java
public class ShoppingCart {

    private int totalItems;
    private double totalPrice;
    private boolean checkedOut;

    public ShoppingCart() {
        totalItems = 0;
        totalPrice = 0.0;
        checkedOut = false;
    }

}
```
