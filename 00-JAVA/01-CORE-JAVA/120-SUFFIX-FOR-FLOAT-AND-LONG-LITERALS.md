# 1) Suffix for Float Literals
In Java, by default **Floating Point Numbers** like `10.5` are treated as **double**.  
So to store a decimal value in **float**, we must use the **suffix `f` or `F`**.
**Example:** `10.5f`, `99.99F`
# 2) Suffix for Long Literals
In Java, by default **Non-Floating Point Numbers** like `1000` are treated as **int**.  
So to store a large integer value in **long**, we must use the **suffix `l` or `L`**.
**Example:** `10000000000L`, `5000l`
