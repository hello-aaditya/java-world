# `sorted()` Based Questions
### 1 Sort Numbers in Ascending Order
### Solution
```java
public static void main(String[] args) {
		
		List<Integer> numbers = Arrays.asList(45, 12, 78, 23, 9, 56, 34);
		
		numbers.stream()
				.sorted()
				.map(n -> n + " ")
				.forEach(System.out::print);

	}
	```
