# Getting & Setting Name of A Thread
Every thread in Java has some name. it may be default name generated by JVM or customized name provided by programmer.

We can get and set name of a thread by using the following two ways of `Thread` class:
- `public final String getName();`
-  `public void setname(String name);`

Example:
```java
class MyThread extends Thread {
	
}
public class ThreadDemo {

	public static void main(String[] args) {
		
		System.out.println(
			Thread.currentThread().getName()
		); // main
		
		MyThread t = new MyThread();
		
		System.out.println(t.getName()); // Thread-0
		
		Thread.currentThread().setName("Alpha");
		
		System.out.println(
			Thread.currentThread().getName()
		); // Alpha
	}
}
```
We can get current executing thread object by using **`Thread.currentThread()`** method.
```java
class MyThread extends Thread {
	
	@Override
	public void run() {
		System.out.println(
			"run method is executing by Thread: " +
			Thread.currentThread().getName()
		); // run method is executing by Thread: Thread-0
	}
}
public class ThreadDemo {

	public static void main(String[] args) {
		
		MyThread t = new MyThread();
		t.start();
		
		System.out.println(
			"main method is executing by Thread: " +
			Thread.currentThread().getName()
		); // main method is executing by Thread: main
	}
}
```
