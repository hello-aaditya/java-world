# Process To Add A JAR As A Dependency
- Right-click your Java project in the **Package Explorer** and select **Properties**.
![](step-1.png)
- Click on **Java Build Path** in the left sidebar, then select the **Libraries** tab.
![](step-2.png)
![](step-3.png)
- Ensure **Classpath** is selected.
![](step-4.png)
- Click **Add JARs...** (if the JAR is inside your project folder) or **Add External JARs...** (if it is stored elsewhere on your computer).
- Select your JAR file and click **OK** or **Open**, then click **Apply and Close**.
