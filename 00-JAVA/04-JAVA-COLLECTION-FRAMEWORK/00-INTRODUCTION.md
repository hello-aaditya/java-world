# What is Java Collection Framework (JCF)?
Before JCF came into the picture, if we wanted to store a group of data in Java, we used **Arrays**.

But Arrays had two problems:
1. **Fixed size** — size has to be decided at the time of declaration and Can't increase or decrease it later.
2. **No built-in methods** — sorting, searching, removing — everything had to be written manually.

So Java introduced the **Collection Framework** to solve these problems.

---
**Java Collection Framework is a set of ready-made classes and interfaces** that provides pre-built data structures like List, Set, Queue — so that we don't have to write everything from scratch.

It gives us:
1. **Dynamic size** — grows and shrinks automatically, no need to fix size at the start.
2. **Built-in methods** — add, remove, sort, search — everything is already there.
3. **Different data structures** — ArrayList, HashSet, TreeMap etc. for different use cases.
