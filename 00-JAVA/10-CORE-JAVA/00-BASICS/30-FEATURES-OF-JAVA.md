# Features of Java
Java keeps getting better with every new version, and each version has introduced even more powerful features.  
However, the **core features of Java** — or we can say, the **fundamental characteristics** that make it stand out from other programming languages — have remained the same and continue to define its strength.
and these features are-
1. **Simple**
2. **Object-Oriented**
3. **Platform Independent**
4. **Secure**
5. **Robust**
6. **Multithreaded**
7. **Architecture Neutral**
8. **Portable**
9. **High Performance**
10. **Distributed**
11. **Dynamic**
12. **Interpreted**

# 1. Simple
- Java is very **easy-to-learn** programming language. 
- It inherits many features from C, C++ and removes complex features like *pointers*, *operator overloading*, *multiple inheritance*, *explicit memory allocation* etc. It provides automatic **garbage collection**.
# 2. Object-Oriented
- Java is an **Object-Oriented Programming Language (OOPL)**, which means it builds programs around **objects that represent real-world things**, not just logic or functions.
- It helps us to build code that remains **reusable, maintainable, and secure** through key concepts of OOP such as:
	- Class and Object
	- Encapsulation
	- Inheritance
	- Polymorphism
	- Abstraction
# 3. Platform Independent
- Java is **platform independent**, which means the same program can run on **any operating system** without modification.
- When we compile a Java program, it doesn’t generate machine code. Instead, it produces **bytecode** (stored inside `.class` file).
- This bytecode is then executed by the **Java Virtual Machine (JVM)**, which acts as a bridge between the program and the underlying operating system.
- That’s why Java is often described as **“Write Once, Run Anywhere (WORA)”**.
# 4. Secure
- Java is designed with a strong focus on **security** right from the beginning.
- It removes risky features like **pointers** and uses **automatic memory management** to prevent unauthorized access.
- Additionally, features such as **bytecode verification**, **exception handling**, and **access modifiers** add extra layers of protection.
# 5. Robust
- Java is a **robust** programming language. key features such as 
	- **Memory management**
	- **automatic garbage collection**
	- **exception handling** 
	are designed in such a way so that they can easily handle *errors* and *unexpected situations* effectively.
# 6. Multithreaded
Java supports **multithreading**, which means it can run **multiple tasks simultaneously within a single program**. by doing so the applications become faster, more efficient, and responsive.
# 7. Architecture Neutral
- Java is architecture neutral, which means when we compile a Java program, it doesn’t generate machine code. Instead, it produces **bytecode** (stored inside `.class` file).
- This bytecode is then executed by the **Java Virtual Machine (JVM)**, which acts as a bridge between the program and the underlying operating system.
- As a result, Java programs can run on **any system without modification**, which reflects true **portability and flexibility** of Java.
# 8. Portable
- Java is architecture neutral, which means when we compile a Java program, it doesn’t generate machine code. Instead, it produces **bytecode** (stored inside `.class` file).
- This bytecode is then executed by the **Java Virtual Machine (JVM)**, which acts as a bridge between the program and the underlying operating system.
- As a result, Java programs can run on **any system without modification**, which reflects true **portability**.
# 9. High Performance
- Java is designed for **high performance** using **Just-In-Time (JIT) compilers**, which convert bytecode into **native machine code** at runtime.
- This allows Java programs to **run faster and respond efficiently**.
# 10. Distributed
- Java is designed for **distributed computing**, which means it can work over **networks** to share resources and data.
- Features like **Remote Method Invocation (RMI)** and **sockets** allow Java programs to **communicate and collaborate** across multiple systems.
# 11. Dynamic
- Java is **dynamic** because it loads **classes and libraries only when needed**, rather than all at once, which makes programs faster and more efficient.
- Java uses **reflection**, **dynamic loading**, and **runtime linking** to achieve this. It’s helpful in building apps that **grow or change over time**, like **plugin-based systems**.
# 12. Interpreted
- Java is partially interpreted, which means the compiled bytecode is read and executed by the JVM at runtime. 
- This makes debugging and testing easier, as the program runs step by step. It also allows faster development cycles, especially when testing small changes.
