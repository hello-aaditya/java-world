# Why is OOP Needed?
## 1. Problems with Procedural-Oriented Programming (POP)
> In Procedural-Oriented Programming, data and functions are separate. As software grows larger, it becomes difficult to maintain because:
> 1.  Any function can modify shared data.
> 2.  Code re-usability becomes limited.
> 3. Adding new features becomes risky.
> 4. Application becomes difficult to manage and scale.
## 2. How OOP Solves These Problems
> Object-Oriented Programming solves these issues by organizing software into objects, where each object encapsulates both data and the methods that operate on that data. This improves data security, reduces code duplication, and makes different parts of the application independent and easier to maintain.
## 3. What We Achieve by Following OOP Principles
> - Encapsulation -> 
> - Inheritance -> 
> - Polymorphism -> 
> - Abstraction -> Hides the core logic and expose only required functionalities.

As a result, applications become:
- Modular
- Reusable
- Maintainable
- Scalable
- Secure
- Easier to test
- Easier for teams to develop collaboratively
