# INTRODUCTION OF JAVA
- **Java** is a **high-level, object-oriented programming language** developed by **Sun Microsystems**, which was later acquired by **Oracle in 2010**.

- Java was originally developed under the **Green Project** by **James Gosling**, and its initial name was **Oak**.  
    Later, in **1995**, it was renamed to **Java**.
    
- Currently, Java is maintained by **Oracle** as well as **OpenJDK**, where OpenJDK is **open source**.  
- Java supports in **almost all operating systems** and is widely used in **enterprise, web, and application development**.
- It follows the concept of **Object-Oriented Programming (OOP)**.  
    _OOP is a way of writing programs where instead of just writing **functions and logic**, we organize everything around **objects** that represent real-life entities._
    
- One of the main features of Java is **WORA (Write Once, Run Anywhere)**.  
    It means that once we compile Java code into **bytecode**, it can run on any platform that has a **JVM (Java Virtual Machine)**.
    
- Java 
	- source file uses: **`.java`** extension
	- compiled file uses: **`.class`** extension
	- packaged file uses: **`.jar`** extension
