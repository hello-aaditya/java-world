# Different Main Method Syntax

| #   | syntax                                    | What It Does                               |
| --- | ----------------------------------------- | ------------------------------------------ |
| 1.  | `public static void main(String[] args)`  | Standard syntax for Java programs.         |
| 2.  | `static public void main(String[] args)`  | Swaps the order of `public` and `static`.` |
| 3.  | `public static void main(String args[])`  | Another way to write arrays.               |
| 4.  | `public static void main(String... args)` | A way to handle many inputs.               |
| 5.  | `public static void main(String[] raju)`  | Allows custom input names                  |
