# Anonymous Class
> An **anonymous inner class** is a class **without a name**, created for one-time use. 
>  
It is used when you need to quickly provide an implementation of an abstract class or interface **without creating a separate child class file**.

| Can create the class and the object **at the same time**. |
| --------------------------------------------------------- |
## Why Do We Need Anonymous Inner Classes?
Sometimes we create a whole child class **just to override one method**.  
Instead of:
- writing a separate new class,
- writing the override,
- then creating the object…

We can do **all of this in one place**, using an anonymous class.
### Syntax
```java
ParentType obj = new ParentType() {
    // method implementation
};
```

### Example 1: Using Abstract Class

#### Program.java
```java
abstract class Program {
    abstract void display();
}
```
#### Main.java (traditional way – longer)
```java
public class ProgramChild extends Program {
    @Override
    void display() {
        System.out.println("Inside display");
    }
}

public class Main {
    public static void main(String[] args) {
        ProgramChild p = new ProgramChild();
        p.display();
    }
}
```
#### Anonymous Class (short way – no child class needed)
```java
public class Main {
    public static void main(String[] args) {

        Program p = new Program() {
            void display() {
                System.out.println("Inside display");
            }
        };

        p.display();
    }
}
```
#### Output
```markdown
Inside display
```

### Example 2: Anonymous Class with Interface
#### Interface
```java
interface Greeter {
    String greet();
}
```
#### Anonymous Inner Class Usage
```java
public class Main {
    public static void main(String[] args) {

        Greeter anonymousGreeter = new Greeter() {
            public String greet() {
                return "Hello from Anonymous Inner Class!";
            }
        };

        System.out.println(anonymousGreeter.greet());
    }
}
```
#### Output
```markdown
Hello from Anonymous Inner Class!
```
### Example 3: Math Operation Anonymous Class
```java
interface MathOperation {
    int operate(int a, int b);
}

public class Main {
    public static void main(String[] args) {

        MathOperation addition = new MathOperation() {
            public int operate(int a, int b) {
                return a + b;
            }
        };

        int result = addition.operate(5, 3);
        System.out.println("5 + 3 = " + result);
    }
}
```
#### Output
```markdown
5 + 3 = 8
```
