# Introduction
> Inner classes in Java allow us to define a class **inside another class**.

Inner Class help in **grouping logic**, **improving encapsulation**, and **writing cleaner code**.

## Types of Inner Classes in Java
Java provides four types of inner classes:
1. **Member Inner Class (Non-Static Inner Class)**
2. **Static Nested Class**
3. **Local Inner Class**
4. **Anonymous Inner Class**
