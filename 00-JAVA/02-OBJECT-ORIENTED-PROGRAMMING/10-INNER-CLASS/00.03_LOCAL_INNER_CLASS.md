# Local Inner Class
> A **local inner class** is a class defined **inside a method**.  
Just like a local variable is limited to a method, a local class is also limited to that method only.


| Its scope is only within the method where it is declared. |
| --------------------------------------------------------- |
### Example:
#### Program1.java
```java
public class Program1 {
    int a = 10;

    void myMethod() {

        // local inner class
        class Program2 {
            int b = 20;

            void displayProgram2() {
                System.out.println("Inside Program2:");
                System.out.println("b = " + b);
                System.out.println("a = " + a);
            }
        }

        Program2 p2 = new Program2();
        p2.displayProgram2();
    }

    void displayProgram1() {
        System.out.println("a = " + a);
    }
}
```
#### Main.java
```java
public class Main {
    public static void main(String[] args) {
        Program1 p1 = new Program1();
        p1.myMethod();
        p1.displayProgram1();
    }
}
```
#### Output
```markdown
Inside Program2:
b = 20
a = 10
a = 10
```
