# 1. Lambda Expression
> A **lambda expression** is a short way of writing a method — **a method without a name** (anonymous method).
> 
> It is mostly used to implement **functional interfaces**.

| **Functional Interface = an interface with exactly one abstract method.**  <br>(Annotated using `@FunctionalInterface`) |
| ----------------------------------------------------------------------------------------------------------------------- |
**Note:** 
Lambda expressions were introduced in **Java 8**.
## 2. Why Do We Use Lambda Expressions?
Before lambda, to implement a functional interface, we had to write:
- A whole child class, _or_
- An anonymous inner class.

Lambda expressions make this process **short, clean, and readable**.

Example without lambda:
```java
ProgramInterface p = new ProgramInterface() {
    public void display() {
        System.out.println("Inside display");
    }
};
```
Same thing with lambda:
```java
ProgramInterface p = () -> System.out.println("Inside display");
```
Much shorter.
## 3. Rules of Lambda Expression
- No method name
- No return type (compiler infers it)
- Parameter types are optional
- Can have body with `{}` only when multiple statements

## 5. Example 1: No-Parameter Lambda
#### ProgramInterface.java
```java
@FunctionalInterface
interface ProgramInterface {
    void display();
}
```
#### Main.java
```java
public class Main {
    public static void main(String[] args) {

        ProgramInterface p = () -> System.out.println("Inside display");
        p.display();
    }
}
```
#### Output
```markdown
Inside display
```
> ✔ If the body has only **one statement**, `{}` is optional.

## Example 2: Lambda with Parameters
#### ProgramInterface.java
```java
@FunctionalInterface
interface ProgramInterface1 {
    void addition(int a, int b);
}
```
#### Main.java
```java
public class ProgramInterface1Main {
    public static void main(String[] args) {

        ProgramInterface1 p = (int a, int b) -> {
            System.out.println(a + " + " + b + " = " + (a+b));
        };

        p.addition(5, -5);
    }
}
```
#### Output
```markdown
5 + -5 = 0
```
### Shorter version:
```java
ProgramInterface1 p = (a, b) -> System.out.println(a + " + " + (a+b));
```
## Example 3: Lambda with Return Value
#### ProgramInterface.java
```java
@FunctionalInterface
interface ProgramInterface1 {
    int addition(int a, int b);
}
```
#### Main.java
```java
ProgramInterface1 p = (a, b) -> {
    return a + b;
};

// or shorter:
ProgramInterface1 p = (a, b) -> (a + b);

System.out.println(p.addition(5, -5));
```
#### Output
```markdown
0
```
> ✔ If the body has only **one return statement**, `{}` and `return` are optional.

## Important Notes
- Lambda expressions **can only be used with functional interfaces**.
- If body has multiple statements → `{}` required.
- If body has only one statement → `{}` optional.
- If returning value:
    - With `{}` → must use `return`.
    - Without `{}` → return keyword not required.

## Question-1
#### Subtask 1: Create Functional Interface and Lambda Expression

- Create a functional interface named `Greeter` with a method `greet()` that returns a `String`
- In the main method, create a lambda expression that implements the `Greeter` interface
- The lambda expression should return the string `"Hello from Lambda!"`
- Assign the lambda expression to a variable `lambdaGreeter` of type `Greeter`

#### Subtask 2: Demonstrate the Use of Lambda Expression

- In the main() method, call the `greet()` method on the `lambdaGreeter` object and print the result
## Solution
```java
interface Greeter {
    String greet();
}

public class Main {
    public static void main(String[] args) {
        // Subtask 1: Create lambda expression implementing Greeter interface
        Greeter lambdaGreeter = () -> "Hello from Lambda!";
        
        // Subtask 2: Call greet() method and print the result
        System.out.println(lambdaGreeter.greet());
    }
}
```
**Output:**
```markdown
Hello from Lambda!
```
